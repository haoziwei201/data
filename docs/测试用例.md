# 测试用例

自动化测试：`python -m pytest -q`（71 个用例，含单元与 API 集成，连接本地 MongoDB，
使用独立测试库 `survey_test_db`，每个用例前后自动清空）。
端到端冒烟：先 `python run.py`，再 `python scripts/smoke_test.py`（28 步）。

## 二、端到端冒烟（scripts/smoke_test.py，对运行中的服务）

步骤：注册 A/B → A 创建问卷（开匿名）→ 加 4 题（Q1 选"否"跳 Q3）→ 发布 →
B 打开问卷 → step 验证导航 → 非法答案 400 → B 提交 → 匿名提交 → 匿名再提交 →
暂停收集（填写 403）→ 暂停期加题（201）→ 继续收集（填写恢复 200）→
新问卷导入内置模板（4 题）→ 直接发布 → step 验证导入问卷的跳转 →
A 查看统计 → 删除导入的问卷（级联，填写链接变 404）。

最近一次运行结果（28 步全部 PASS）：

```
总答卷数: 3
第1题 你是否年满18岁: 是=1, 否=2 (回答3人)
第2题 你的年龄: 平均=20 最小=20 最大=20
第3题 你喜欢的水果: 苹果=1, 香蕉=1, 西瓜=1, 葡萄=1 (回答3人)
第4题 留言: []
```

## 三、手工测试（网页操作路径）

| 编号 | 步骤 | 期望 |
|---|---|---|
| H1 | 打开 http://127.0.0.1:5000 注册两个账号 | 均进入"我的问卷"页 |
| H2 | 账号 A 创建问卷（勾选允许匿名），点击「导入题目模板 → 内置测试模板」 | 一键获得 4 道配好跳转的题 |
| H3 | 在编辑页顶部点击「发布问卷」 | 当前页直接发布，状态变"收集中"，显示分享链接 |
| H4 | 复制链接到无痕窗口打开 | 免登录直接填写（匿名问卷） |
| H5 | 按跳转路径作答（选"否"应跳过年龄题） | 题目顺序符合跳转配置 |
| H6 | 必答题留空点"下一题" | 页面提示"本题必答" |
| H7 | 提交答卷后回到 A 账号查看统计 | 选项计数、平均值、文本列表正确 |
| H8 | A 在编辑页点击「暂停收集」，修改一道题后「继续收集」 | 暂停期间填写链接提示已暂停；恢复后可正常填写 |
| H9 | 暂停期删除某多选题的一个选项（已有该选项答卷），看统计 | 出现"（已删除的选项）"行，计数不丢 |
| H10 | A 关闭问卷后再打开填写链接 | 提示问卷已关闭 |
| H11 | B 登录后访问 A 的问卷编辑页/统计 | 通过 URL 直接访问 API 返回 403，页面提示无权限 |
| H12 | 未登录用户打开"需登录"问卷链接 → 点"去登录/注册" → 注册新账号 | 注册成功后自动回到该问卷填写页，而非"我的问卷"页 |
| H13 | 未登录用户打开"需登录"问卷链接 → 用已有账号登录 | 登录后同样自动回到该问卷 |
| H14 | A 删除一份有答卷的问卷 | 确认框显示题目数与答卷数；删除后列表消失、填写链接 404 |
